Assembling a computer

Build and disassemble desktops and laptops, then install software.

1. Step-by-step desktop assembly

  1. Prepare a clean workspace and ground yourself.
  2. On the motherboard (outside the case), fit the CPU, then the cooler with thermal paste, then the RAM and any M.2 SSD.
  3. Fit the I/O shield and motherboard standoffs, then mount the board in the case.
  4. Install the PSU and drives.
  5. Connect the 24-pin power, CPU power, SATA and graphics-card power cables, the fans and the front-panel connectors (check the motherboard manual).
  6. Fit the graphics card, tidy the cables, then connect a monitor and keyboard and power on to test (POST) before closing the case.

2. Laptop disassembly basics

  • Shut down, unplug and remove the battery if it is removable. Hold the power button for about 10 seconds to discharge.
  • Photograph each stage and sort screws by location; screw lengths differ.
  • Remove the back panel, then disconnect the battery connector first.
  • Flat ribbon cables use a small latch: flip it up before sliding the cable out.
  • Reassemble in reverse order and test before fitting every screw.

3. Installing the operating system and drivers

  1. Create a bootable USB installer (for Windows, with Microsoft’s Media Creation Tool).
  2. Open the BIOS/UEFI and set the USB as the first boot device.
  3. Follow the installer, choosing the drive or partition for the OS.
  4. Install drivers: chipset, graphics, network and audio.
  5. Run Windows Update, then install antivirus and the user’s programs.
